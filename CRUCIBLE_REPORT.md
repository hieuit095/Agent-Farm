### Bug 1: Duplicate Column Name in Schema Migration
**File:** `farm_agent/orchestrator/memory.py`, line ~143
**Severity:** P0 (pipeline crash)
**Status:** ✅ FIXED

**Root Cause:** The migration loop checked for `"already exists" in str(e)` but SQLite's error message is `"duplicate column name: ci_fix_attempts"`. The condition didn't match, causing `OperationalError` to be re-raised and crashing the pipeline.

**Fix:** Extended the condition to also check for `"duplicate column name"`:
```python
if "already exists" in str(e) or "duplicate column name" in str(e).lower():
```

### Bug 2: Missing `escape_html_xss` Function (XSS Sanitization)
**File:** `farm_agent/generator/engine.py`
**Severity:** P2 Security
**Status:** ✅ FIXED

**Root Cause:** The task requires an `escape_html_xss` function that strips `<script>`, `onerror=`, and `javascript:` patterns from issue/PR bodies. This function did not exist. Only AI disclosure (Gag Order) sanitization was implemented.

**Fix:** Added:
```python
_XSS_SCRIPT_RE = re.compile(r"<script[^>]*>.*?</script>", re.IGNORECASE | re.DOTALL)
_XSS_EVENT_HANDLER_RE = re.compile(r"\bon\w+\s*=", re.IGNORECASE)
_XSS_JAVASCRIPT_RE = re.compile(r"javascript\s*:", re.IGNORECASE)

def escape_html_xss(text: str) -> str:
    text = _XSS_SCRIPT_RE.sub("[XSS-STRIPPED]", text)
    text = _XSS_EVENT_HANDLER_RE.sub("xss-blocked=", text)
    text = _XSS_JAVASCRIPT_RE.sub("xss-blocked:", text)
    return text
```

Applied in `pr/manager.py` when generating issue bodies (line 375):
```python
safe_title = escape_html_xss(_sanitize_text(finding.title, "issue title"))
safe_description = escape_html_xss(_sanitize_text(finding.description, "issue description"))
```

**Test Results:**
```
Input:  '<script>alert(1)</script>'
Output: '[XSS-STRIPPED]'  ✓
Input:  '<img src=x onerror=alert(1)>'
Output: '<img src=x xss-blocked=alert(1)>'  ✓
Input:  'javascript:alert(1)'
Output: 'xss-blocked:alert(1)'  ✓
```

### Bug 3: Gag Order Regex Missing "farm_agent" and "I was developed by"
**File:** `farm_agent/generator/engine.py`
**Severity:** P2 Security
**Status:** ✅ FIXED

**Root Cause:** The Gag Order regex was missing `"farm_agent"` and `"I was developed by"` patterns. Only `"contribai"` was included.

**Fix:** Extended `_GHOST_DISCLOSURE_RE` and `_STRIP_AI_RE`:
```python
r"(?i)(as an ai|ai generated|language model|openai|minimax|"
r"automated bot|generated by ai|ai assistant|contribai|farm_agent|"
r"generated by this|this pr was generated|i was developed by)"
```

**Test Results:** All 14 test cases pass including "farm_agent" and "I was developed by" patterns.
