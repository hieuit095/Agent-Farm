## Overview

Farm-Agent is a highly advanced autonomous system designed to automatically discover open-source GitHub repositories, identify vulnerabilities and quality issues, generate precise code fixes, and submit pull requests. Leveraging advanced LLM capabilities and robust containerized validation, it contributes safely and effectively to real-world codebases without human intervention.

## Key Features

- **Polyglot Sandbox Validation:** Uses isolated Docker containers to execute, validate, and test generated patches across 12 languages (Python, Node.js, Rust, Go, etc.) before any Pull Request is created.
- **Multi-Strategy Analysis & Bloodhound Red Team:** Concurrently runs security (via Semgrep), code quality, documentation, and UI/UX analyzers against repository file trees to pinpoint high-impact flaws.
- **X-Ray Context Vision:** Builds a local ChromaDB Retrieval-Augmented Generation (RAG) index to ensure code patches are contextually accurate across multiple files.
- **PR Patrol:** Autonomously monitors open PRs for maintainer feedback, uses an LLM to classify comments, and autonomously generates and pushes code fixes.
- **Anti-Farming Filter:** A strict, zero-tolerance gatekeeper that blocks trivial findings (e.g., formatting, typo fixes) and drops documentation-only PRs to prevent spamming maintainers.
- **Super Human Mode:** A relentless autonomous daemon orchestrated via docker-compose, utilizing a Terminator execution loop to maximize PR throughput up to daily API caps.
- **Multi-Model Routing:** Intelligently assigns different tasks (e.g., coding, analysis, fallback) to the most capable models (MiniMax, OpenRouter, Gemini, etc.) dynamically.

## System Architecture (High-Level)

Farm-Agent orchestrates its operations via a Rich/Click-based CLI interface. The core execution engine (`ContribPipeline`) interfaces with an LLM Provider (utilizing MiniMax ABAB models and OpenRouter) and the GitHub REST/GraphQL API.

The agent's execution follows a sequential pipeline: **Discovery -> Gate -> Analysis -> Engine -> Sandbox -> PR**. During analysis, the system creates a ChromaDB RAG store for precise code retrieval. All patches generated by the AI Engine are strictly validated inside a tightly restricted Docker Sandbox (`sandbox_isolated` network). State and PR outcomes are securely managed locally using an asynchronous SQLite database (WAL mode).

## Getting Started

### Prerequisites

- **Python:** >= 3.11
- **Docker:** >= 7.1 (Required for Polyglot Sandbox Validation)
- **GitHub PAT:** A Personal Access Token with `repo`, `read:org`, and `workflow` scopes.
- **LLM API Key:** Minimax API key (default) and/or OpenRouter API key.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/hieuit095/Agent-Farm.git
   cd Agent-Farm
   ```

2. Install the package and development dependencies:
   ```bash
   pip install -e .[dev]
   ```

### Environment Variables

Configure the agent by copying `config.example.yaml` to `config.yaml` and `.env.example` to `.env`. The core required environment variables include:

- `GITHUB_TOKEN`: Your primary GitHub Personal Access Token (used for write operations).
- `GITHUB_SECONDARY_TOKENS`: Additional tokens (comma-separated) for GET request rotation to manage rate limits.
- `MINIMAX_API_KEY`: Your Minimax API Key for primary code generation and analysis.
- `OPENROUTER_API_KEY`: API key for Bloodhound Red Team audits (optional but recommended).

## Usage

Farm-Agent provides a comprehensive suite of CLI commands (`farm_agent`):

- `farm_agent run`: Auto-discover repos matching config criteria, analyze them, generate patches, and submit PRs.
- `farm_agent target <url>`: Target a specific GitHub repository URL directly.
- `farm_agent hunt`: Execute an aggressive multi-round discovery and contribution loop.
- `farm_agent hunt-circular`: Continuously process a round-robin list of targeted repositories.
- `farm_agent solve <url>`: Fetch open issues in a specific repository, estimate complexity, and solve them.
- `farm_agent analyze <url>`: Run static analysis and the Red Team engine on a repo without creating PRs.
- `farm_agent superhuman`: Start the 24/7 continuous autonomous engine daemon.
- `farm_agent patrol`: Check open Farm-Agent PRs for maintainer feedback and autonomously reply/fix.
- `farm_agent status`: Show the current status of all submitted PRs.
- `farm_agent stats`: Display overall operational statistics and metrics.
- `farm_agent config`: View the currently loaded configuration.
